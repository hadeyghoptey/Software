## HTML Basics (Markdown Format)

### 1. HTML Document Structure

* `<!DOCTYPE html>` – Declares HTML5
* `<html> ... </html>` – Root element
* `<head> ... </head>` – Metadata, title, links
* `<body> ... </body>` – Visible content

---

### 2. Opening and Closing Tags

* General format:

  * `<tagname> content </tagname>`
* Examples:

  * `<p>This is a paragraph.</p>`
* Self-closing (void) tags (no closing tag):

  * `<br>`
  * `<img>`
  * `<link>`

---

### 3. Headings (h Tags)

* `<h1> ... </h1>` – Main heading
* `<h2> ... </h2>`
* `<h3> ... </h3>`
* `<h4> ... </h4>`
* `<h5> ... </h5>`
* `<h6> ... </h6>` – Smallest heading

---

### 4. Paragraph Tag

* `<p> ... </p>` – Paragraph of text

---

### 5. Text Formatting Tags

* `<b> ... </b>` – Bold / important text
* `<i> ... </i>` – Italic text
* `<span> ... </span>` – Inline container

---

### 6. Links and Images

* `<a href="URL">Link Text</a>` – Hyperlink
* `<img src="image.jpg" alt="description">` – Image

---

### 7. Lists

#### Ordered List (Numbered)

* `<ol>`

  * `<li>Item 1</li>`
  * `<li>Item 2</li>`
* `</ol>`

#### Unordered List (Bulleted)

* `<ul>`

  * `<li>Item 1</li>`
  * `<li>Item 2</li>`
* `</ul>`

---

### 8. Table Structure

* `<table>` – Table container
* `<tr>` – Table row
* `<th>` – Header cell
* `<td>` – Data cell

### 9. Basic Form Tags

* `<form> ... </form>`
* `<label> ... </label>`
* `<input>`
* `<textarea> ... </textarea>`
* `<button> ... </button>`
* `<select>` with `<option>`
