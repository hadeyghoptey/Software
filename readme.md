Personal Portfolio Website Using HTML

📂 Folder Structure (Mandatory)
Portfolio/
│
├── index.html      (Home Page)
├── about.html      (About Me / Social Media)
├── contact.html    (Contact Page)
        └── your-image.jpg

📄 Page Requirements
1️⃣ index.html – Home Page

Purpose: Introduce yourself

Must Include:

Your photo (<img>)

Your name (<h1>)

Short description (<p>)

Ordered list (<ol>) of:

Skills

Hobbies

Goals

Navigation links to:

Home

About

Contact

2️⃣ about.html – About / Social Media

Purpose: Share online presence

Must Include:

Short about section (<p>)

Unordered list (<ul>) of social media links:

Facebook

Instagram

LinkedIn

GitHub

Links must:

Open in a new tab (target="_blank")

Navigation links to all pages

3️⃣ contact.html – Contact Page

Purpose: Collect user information

Must Include a Form with:

Name (text)

Email (email)

Message (textarea)

Submit button

Form Rules:

Use <label> for each input

Use required attribute

Use name attribute

🧠 HTML Rules (Strict)

❌ No CSS

❌ No JavaScript

✅ HTML only

Proper indentation

Use semantic tags:

<header>

<nav>

<main>

<section>

<footer>
